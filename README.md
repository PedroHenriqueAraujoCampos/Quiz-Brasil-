# Quiz-Brasil

Um quiz interativo desenvolvido com HTML e CSS para testar conhecimentos sobre o Brasil, incluindo temas como:

- História
- Cultura
- Geografia
- Futebol
- Curiosidades brasileiras

O projeto possui perguntas de múltiplos formatos, tabela de pontuação, área de verificação de respostas e uma interface personalizada inspirada nas cores da bandeira do Brasil.

---

## 📸 Preview

O usuário pode responder perguntas utilizando:

- múltipla escolha
- campos de texto
- seleção múltipla
- menu suspenso
- upload de arquivo
- campos de data

Além disso, o projeto conta com:

✅ tabela de pontuação  
✅ seção de respostas  
✅ formulário de feedback  
✅ visual temático brasileiro  
✅ layout responsivo simples e organizado
