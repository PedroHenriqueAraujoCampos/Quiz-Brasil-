QUIZ-BRASIL

Um quiz interativo desenvolvido para testar conhecimentos sobre o Brasil, incluindo temas como historia, cultura, geografia, futebol e curiosidades. O projeto utiliza uma interface personalizada inspirada nas cores da bandeira nacional, com foco na organizacao visual e na experiencia do usuario.

#Funcionalidades do Projeto

-O usuario pode responder as perguntas utilizando diferentes formatos de entrada, o que permite uma pratica abrangente de elementos de formulario:
-Multipla escolha e selecao multipla
-Campos de texto e menus suspensos
-Upload de arquivos e selecao de datas
-Tabela de pontuacao para registro de desempenho
-Seção de verificacao de respostas
-Formulario de feedback para interatividade
-Layout responsivo adaptado para diferentes telas

#Tecnologias Utilizadas
-HTML5
-CSS3

#Objetivo e Aprendizados
Este projeto foi desenvolvido com o foco em aplicar conceitos fundamentais de desenvolvimento web, tais como:
- Estruturacao semantica de paginas
- Criacao e formatacao de formularios complexos
- Organizacao de dados em tabelas
- Estilizacao de componentes e personalizacao de interface
- Adaptacao de layout e hierarquia visual

#Observações
-O projeto teve como base um exercicio de estudos, mas foi completamente transformado e personalizado com um novo tema, estrutura de perguntas original e uma identidade visual propria desenvolvida do zero.
